# MemoryTaxonomy

记忆分类学：认知科学的记忆分类法被工程界**直接借用为架构清单**。按两条轴切分——**存哪里**（上下文窗口内 / 外部存储）× **存多久**（短期 / 长期）。

判据只有一条：**这条信息「要不要跨会话活」→ 决定放上下文还是外部存储。**

## 七类记忆

| 类型 | 内容 | 时长 / 位置 |
|---|---|---|
| **工作记忆** Working | 当前推理所需 | 短期 · 上下文窗口内 |
| **语义记忆** Semantic | 事实 · 偏好 · 领域知识（**不含时间**） | 长期 · 外部 |
| **情景记忆** Episodic | 具体事件 · 会话记录 · 成败经历（**含时间**） | 长期 · 外部 |
| **程序记忆** Procedural | 怎么做 · 技能 · 工作流 · 行为规则 | 长期 · 规则/权重 |
| **检索记忆** Retrieval | 窗口外的文档，按需拉回（RAG） | 混合 · 向量库 |
| **参数记忆** | 训练进权重的世界知识 | 常被提及，不在前四类 |
| **前瞻记忆** | 未执行的未来意图 | 常被提及，不在前四类 |

**工程落地最常用前三类：工作 + 语义 + 情景**；程序记忆常以 skill / runbook 形式存在于外部（参见 [[AgentSkills]]）。

## 层间桥：巩固

工作记忆 → 长期记忆的转化称为**巩固 Consolidate**：把当前会话中值得留存的信息提炼后写入外部存储。只在当前推理用的放工作记忆；要活到下次会话的才放进外部长期记忆。

## 常见失误

**放错层是记忆设计最常见的失误**——把项目专属约定写进用户级、把临时推理结果写进长期记忆，都会造成「换个项目就串味」或噪声累积。这正是 [[AgentMemory]] 第四铁律「作用域决定归属」要防的问题。
