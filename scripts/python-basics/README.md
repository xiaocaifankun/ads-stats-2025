# Python 基础语法：动手跑一遍

《统计与数据分析》上机前的语法铺垫。五个文件，按顺序跑完即可覆盖后面数据分析要用到的全部语法地基。

纯标准库、零依赖、不联网、不读键盘输入，输出每次完全一致。

## 怎么跑

在 VSCode 里打开本文件夹，任选一种：

| 方式 | 操作 |
| --- | --- |
| 单文件运行 | 打开 `.py` 文件，点右上角 ▶ Run Python File，或按 `Ctrl + F5` |
| 终端运行 | `python scripts/python-basics/01_variables.py`（在仓库根目录执行） |
| 逐行看变量 | 在行号左侧点一下打断点，按 `F5`，用调试面板看每一步的值 |

顺序建议：`01` → `05`，不要跳。`03` 的推导式和 `05` 的 `lambda` 都用到了前面文件的概念。

## 每个文件长什么样

五个文件结构一致，读起来不用重新适应：

1. 顶部文档字符串：学习目标 + 运行方法。
2. `# ==== N. 小节标题 ====` 分节。每节先一两行说明，再是可运行的代码，关键结果的行尾用 `# -> 结果` 标出实际输出。
3. 每节末尾一行 `# 【动手改】`：改一个地方再看结果——比只读代码有用得多。
4. 文末 `# ===== 练习 =====`：4 道题，每题附验证方式（跑出来应该是什么）。
5. 文末 `# ===== 参考答案 =====`：可运行的解答。

想先自己做练习，就把「参考答案」那一段用 `#` 注释掉再运行；跑完再解开对照。
